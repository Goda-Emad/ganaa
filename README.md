# Ganna Emad 🎀 — صفحة هدية عيد الميلاد

موقع صفحة واحدة (HTML + CSS + JS) بدون أي مكتبات خارجية.
افتحي ملف `index.html` مباشرة في المتصفح — لا يحتاج أي تشغيل أو تنصيب.

```
ganna/
├── index.html   ← المحتوى والنصوص
├── style.css    ← التصميم والألوان والحركات
├── script.js    ← القلوب، الظهور عند التمرير، العدّاد التنازلي
└── README.md    ← هذا الملف
```

---

## أول حاجة تعدّليها: تاريخ عيد الميلاد

في ملف `script.js`، أول الملف:

```js
const BIRTHDAY = { month: 12, day: 31 };
```

- `month`: الشهر من **1** (يناير) إلى **12** (ديسمبر)
- `day`: اليوم

لو عايزة تخفّي العدّاد تماماً، اكتبي:

```js
const BIRTHDAY = null;
```

في يوم عيد الميلاد نفسه، العدّاد يعرض رسالة تهنئة تلقائياً.
وتقدرين تغيّري نصّها من المتغيّر `BIRTHDAY_MESSAGE` تحتيه.

## إزاي تعدّلي النصوص

كل مكان محتاج تعديل معلَّم بتعليق فيه كلمة **EDIT** داخل `index.html`:

| القسم | إيه اللي تعدّليه |
|---|---|
| Hero | الاسم، اللقب، الجملة التعريفية |
| رسالة | الفقرة الشاعرية |
| ما يميّزكِ | 4 بطاقات (عنوان + نص + إيموجي) |
| الاقتباس | البيت الشعري ومصدره |
| أم لارا | القصة أو النكتة الخاصة |
| لحظات | 3 ذكريات (مكتوبة حالياً «قريباً...») |
| الخاتمة | التهنئة النهائية والتوقيع |
| الفوتر | سطر الحقوق |

**لإضافة ذكرى رابعة:** انسخي بلوك `<article class="memory-card">` كامل والصقيه،
وغيّري الرقم الروماني (`IV`).

**لإضافة بطاقة خامسة:** نفس الفكرة مع `<article class="card">`.

## تغيير الألوان

كل الألوان في مكان واحد أعلى `style.css` داخل `:root`:

```css
--rose-400: #f07ea6;   /* الوردي الأساسي */
--rose-600: #c73e69;   /* الوردي الغامق */
--plum-900: #3a1f2b;   /* لون العناوين */
--gold:     #d9a441;   /* الذهبي */
```

غيّري قيمة واحدة وستتغيّر الصفحة كلها.

---

## إضافة صور للذكريات

الذكريات حالياً نصّية. لو عايزة تحطي صورة، أضيفي داخل `memory-card`:

```html
<img src="images/memory-1.jpg" alt="وصف الصورة" loading="lazy"
     style="width:100%;border-radius:16px;margin-bottom:1rem" />
```

وأنشئي فولدر `images` جنب الملفات. الصورة `loading="lazy"` يعني مش هتتحمّل
غير لما توصلها، فالصفحة هتفضل سريعة.

## اللي اتحسّن عن النسخة الأصلية

**الأداء**
- خلفية القلوب بقت `<canvas>` واحد بدل مئات عناصر DOM — أخف بكتير على الجوال.
- تشغيل/إيقاف تلقائي للحركات لما التبويب يختفي (توفير بطارية).
- سقف `devicePixelRatio = 2` حتى على شاشات Retina العالية.
- `defer` للسكربت، و`display=swap` للخطوط، وأيقونة SVG مدمجة (صفر طلبات إضافية).
- كل مستمعي التمرير مجمّعين في `requestAnimationFrame` واحد.

**إمكانية الوصول (a11y)**
- رابط «تجاوز إلى المحتوى» للوحة المفاتيح.
- `focus-visible` واضح على كل عنصر تفاعلي.
- العناصر الزخرفية عليها `aria-hidden`، والـ Toast عليه `role="status"`.
- احترام كامل لـ `prefers-reduced-motion` (الحركات تتوقف تماماً).
- نقل التركيز للقسم عند الضغط على رابط داخلي (مهم لقارئ الشاشة).

**الجوال**
- `100svh` بدل `100vh` (يمنع مشكلة شريط العنوان في iOS).
- دعم `env(safe-area-inset-*)` لهواتف الـ notch.
- تعطيل تأثير التوهّج على أجهزة اللمس (`@media (hover: none)`).

**تصميم ومحتوى**
- نظام تصميم بمتغيّرات CSS + ظلال متعدّدة الطبقات.
- عنوان بتدرّج لوني، وتوهّج يتبع الماوس على البطاقات.
- شريط تقدّم للتمرير، زر «العودة للأعلى»، وزر مشاركة الصفحة.
- **عدّاد تنازلي** لعيد الميلاد (جديد).
- استخدام وسوم دلالية: `main`, `article`, `figure`, `blockquote`, `figcaption`.
- خصائص طباعة تجعل الصفحة تُطبع بشكل نظيف.
